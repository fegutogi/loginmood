# Security policy

LoginMood is created and maintained by [Fegutogi](https://fegutogi.com).

## Supported versions

Security fixes are provided for the latest published version. Release candidates are intended for testing and should be updated when a newer candidate or stable release becomes available.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not disclose a suspected vulnerability in a public issue before Fegutogi has had a reasonable opportunity to investigate and prepare a fix.

Include the affected version, WordPress and PHP versions, reproduction steps, impact, and any proposed mitigation. Reports will be acknowledged as soon as practical; response times are not guaranteed.
